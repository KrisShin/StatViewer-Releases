# StatViewer

轻量、实时、专业的 Windows 系统硬件监控工具。完全本地运行,无广告、无遥测、无网络上传。
A lightweight, real-time, professional Windows hardware monitoring tool. Fully local — no ads, no telemetry, no network uploads.

## 功能特性 / Features

- 实时监控:CPU / GPU / 内存 / 磁盘 / 网络 / 电池 / FPS,桌面悬浮窗呈现
- 深度数据:温度、功耗、频率、显存、读写速度、电池健康度
- 现代界面:多套主题、卡片 / 胶囊布局、辉光 / 透明 / 缩放
- 极简安全:完全本地运行,无广告、无遥测、无账号、无网络上传
